This page lists facts about three tools that bind a GraphQL schema to Java code. Each cell names the version it was read from and links its source. The notes below the table list the rows where another tool offers more than this library.

The versions are graphql-java-tools 15.0.0, Spring for GraphQL 2.1.0 with its Spring Boot starter, and this library at the version of this guide. A fact about a later version of another tool is not in the table until a release re-verifies it: the release checklist in `MAINTAINING.md` has a step for that.

== Where the other tools offer more

* *DataLoader*: Spring for GraphQL has `@BatchMapping`, a method-level shortcut for batch loading. This library needs a loader bean and a `DataLoader` parameter.
* *Error handling*: Spring for GraphQL has a resolver chain and an annotated exception handler (`@GraphQlExceptionHandler`). This library maps an exception type to an error with `GraphQLExceptionMapper` beans.
* *Schema discovery*: Spring Boot picks up `.graphqls` and `.gqls` files by default. This library reads `.graphqls` files only.

== Spring concepts and their counterparts

This table is a map of names and not a migration guide.

[cols="3,5", options="header"]
|===
|Spring for GraphQL |This library
|`@Controller` with `@QueryMapping` |A bean with `@GraphQLRootResolver`; the method name is the field name. See <<quickStart,Quick Start>>.
|`@MutationMapping`, `@SubscriptionMapping` |The same annotation on the root resolver; the field decides the operation. A subscription method returns a `Publisher`. See <<subscriptions,Subscriptions>>.
|`@SchemaMapping` |`@GraphQLTypeResolver` on a bean, or a `@GraphQLField` method on a `@GraphQLType` class. See <<resolverContracts,Resolver Contracts>>.
|`@Argument` |A parameter with the name of the argument, or `@GraphQLArgument`. See <<resolverParameters,Resolver Parameters>>.
|`@BatchMapping` |A `BatchLoader` bean and a `DataLoader` parameter. See <<dataLoaders,Data Loaders>>.
|`DataFetcherExceptionResolver`, `@GraphQlExceptionHandler` |`GraphQLExceptionMapper` beans. See <<errors,Errors>>.
|`@ContextValue`, `GraphQLContext` parameters |`@GraphQLContextValue` and `GraphQLContext` parameters, filled by `GraphQLContextContributor` beans. See <<resolverParameters,Resolver Parameters>>.
|===
