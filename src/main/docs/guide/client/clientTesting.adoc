== Replacing the client

A declarative client is an interface bean, so a test can replace it with `@MockBean` of Micronaut Test, as it replaces any other bean, and return the models of your code with no server. Use this for the code that depends on the client. It does not test the client itself, the document or the decoding, and the tests above do.

== The in-process tester

The `micronaut-graphql-tools-testing` module, described on the <<testing,Testing>> page, runs a document against the server of the application in the same process. It tests a server and not a client: it does not use the HTTP client of this module.

== Compile-time checks

A document, a variable or a result type that does not fit the schema fails the build, so most mistakes of a declarative client never reach a test. The example suites compile their client documents against the schema of the application they call. The checks are described on the <<clientChecks,Compile-time checks>> page.
