Library bytecode targets Java 17. It is tested on JDK 17, 21 and 25, with the graphql-java floor, default and ceiling legs on 25, and natively on Oracle GraalVM 25.

Required versus canary:

* Required (blocks merges): JDK 17, 21 and 25, the graphql-java floor, default and ceiling legs.
* Canary (never blocks a merge, runs on `master`, daily and on demand): JDK 27, the newest graphql-java, the newest Kotlin and native on the newest graphql-java.
