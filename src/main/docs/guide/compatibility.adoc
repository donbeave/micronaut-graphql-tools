The library's runtime bytecode targets Java 17. The annotation processor module, `graphql-tools-processor`, targets Java 21 for now, so its javac must run on JDK 21 or later. The library is tested on JDK 17, 21 and 25, with the graphql-java floor, default and ceiling legs on 25, and natively on Oracle GraalVM 25.

Required versus canary:

* Required (blocks merges): JDK 17, 21 and 25, the graphql-java floor, default and ceiling legs.
* Canary (never blocks a merge, runs on `master`, daily and on demand): JDK 27, the newest graphql-java, the newest Kotlin and native on the newest graphql-java.

== Consuming milestone previews

Milestone versions (`1.0.0-M1`, `1.0.0-M2`, ...) and, later, `1.0.0` are published to the GitHub Packages Maven registry of the repository, `https://maven.pkg.github.com/donbeave/micronaut-graphql-tools`, with the Maven coordinates `io.micronaut.graphql.tools:micronaut-graphql-tools`, `micronaut-graphql-tools-processor`, `micronaut-graphql-tools-bom`, `micronaut-graphql-tools-binding` (from `1.0.0-M3`), and `micronaut-graphql-tools-scalars` and `micronaut-graphql-tools-observability` (from `1.0.0-M4`), and `micronaut-graphql-tools-upload` and `micronaut-graphql-tools-security` (from the milestone after `1.0.0-M4`). They are milestone previews from the repository: they are not affiliated with, and not published by, the Micronaut Foundation, and nothing is on Maven Central. There are no snapshots, and a published version is never replaced.

GitHub Packages requires authentication to download, also for public packages. Create a personal access token (classic) with the `read:packages` scope, and hand it to the build:

* Gradle: set `gpr.user` and `gpr.key` in `~/.gradle/gradle.properties`, or export `GITHUB_ACTOR` and `GITHUB_TOKEN`, and add the repository block of the quick start. Do not commit the token.
* Maven: add the repository to the POM, and a `<server>` with the same id, your GitHub user name and the token to `~/.m2/settings.xml`.

Milestone previews carry no compatibility promise: names and behaviour can change between milestones.
