This page describes what is specific to Groovy. Everything else in this guide applies to Groovy classes as it does to Java and Kotlin ones, and every example here is taken from the compiled Groovy suite of the repository (`test-suite-groovy`).

== Properties

A property that Groovy generates is a getter, and, when it is not `final`, a setter. The library binds it as it binds a Java getter or setter: a model field reads the getter, and an input field is set through the setter. The `boolean` property `active` is read through `isActive` or `getActive`, whichever the class has.

== GString

A field of the GraphQL type `String` accepts `GString` as its Java type. A `GString` result is serialized as a string, and so is the value of a `CompletionStage<GString>`:

[source,groovy]
----
include::{groovy-sources}/example/language/GroovyFixtures.groovy[tags=resolver]
----

The library adds no conversion step for this: graphql-java's `String` scalar calls `toString()` on the value when it serializes it, so a field that never returns a `GString` pays nothing, and a `GString` is converted once, when its field is serialized. An async result is serialized by the same scalar after the async boundary completes the field, so there is no second wrapper around the future. Nothing is chosen at run time, and the library makes no dynamic call.

Two limits:

* The GraphQL `ID` type does not accept `GString`; declare `String`, or call `toString()`.
* A field declared `Object` is not accepted for any scalar. Declare `String` or `GString`.

Arguments are never `GString`: graphql-java passes `String` values, so a resolver parameter is declared `String`.

== Async and executors

`@ExecuteOn` on a Groovy bean runs the resolver on the named executor, and a `CompletionStage` return is an async field, exactly as for a Java bean (see the Execution page).

== Native image

Groovy's dynamic features are not native-friendly, so Groovy is covered on the JVM: Spock cannot run in a native image, and the Groovy suite runs on the JVM. The Groovy example application is built as a native executable and smoke-tested by `./gradlew :test-suite-groovy:nativeSmokeTest`. Compile with `@CompileStatic` and without `indy` to keep a Groovy application native-friendly.
