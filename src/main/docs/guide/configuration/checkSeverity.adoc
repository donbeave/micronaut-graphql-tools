Each check has a severity, `micronaut.graphql.tools.checks.<code>`: `fail` (the default), `warn` or `ignore`. `strict` is the shorthand for the checks that have no entry: `true` is every check at `fail`, `false` is every check at `warn`. An explicit entry wins. A check at `ignore` does no work. An unknown code or severity fails the startup. The `allow` settings accept findings: `allow.unreachable`, `allow.inert-directives`, `allow.schema-customizer-directives` and `allow.findings` (lines of the binding manifest). Every entry is validated, and one that no longer applies fails the startup.

An allowed type, or an unreachable type under `checks.unreachable-type` `warn` or `ignore`, also covers the enum, input and scalar types that its fields and arguments use, and those that the input types use in turn. List only the type itself. A type that only a type that is not allowed uses still fails.

== Check codes

Each strict check has a code, from the code registry (`BindingCode` in `graphql-tools-binding`). The code is the key of `micronaut.graphql.tools.checks` (`checks.<code>`), the word in an `allow.findings` line, the token at the start of the startup error (`[unbound-enum-constant] ...`) and the word after `!` in a line of the binding manifest. The five checks that the compile-time check also reports are marked: relaxing one at startup does not relax the compile error. The other five run at startup only.


* `unbound-resolver-method` (compile time)
* `root-method-several-operations` (compile time)
* `unbound-enum-constant` (compile time)
* `unmapped-input-property` (compile time)
* `nullable-primitive` (compile time)
* `unreachable-type`
* `unreachable-value-type`
* `unused-dictionary-entry`
* `interface-read-through-implementation`
* `unwired-directive`

A precedence ambiguity under `precedence: fail` is a binding failure with the code `precedence-ambiguity`, not a check. Its message names the field coordinate, both members and the ways out. Match on `SchemaBindingException#getCode()`; <<exceptions,the error reference>> lists every code of the registry.
