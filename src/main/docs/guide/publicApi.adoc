This page is the reviewed list of the public API of the 1.0 line. A type that is not on it is internal, even when it is `public` in Java, because Micronaut and the library need it to be.

== What is public

A type is public API when it is a top-level `public` type of a package whose name has no `internal` segment, and it is not annotated `@Internal` (`io.micronaut.core.annotation.Internal`). Everything else can change in any release, with no entry on the <<breaks,Breaking Changes>> page: the packages named `internal`, every type annotated `@Internal`, and the nested types of an internal type. The nested types of a public type belong to it.

The modules `micronaut-graphql-tools-opentelemetry` and `micronaut-graphql-tools-bom` have no public type: the first one is configured by the keys of the <<observability,Observability>> page, and the second one holds versions. The test module `test-suite-tck` is not published.

Configuration keys are listed on the <<configuration,Configuration>> page, the one public exception is described on the <<exceptions,Exceptions>> page, and the compile-time options are on the <<compileTimeOptions,Options>> page of the compile-time checks.

[[signatureSnapshot]]
== The signature snapshot

The member signatures of the types listed below are kept in the repository, one file per module, `api/<module>.api` in the directory of the module (for example `graphql-tools/api/micronaut-graphql-tools.api`). The build generates the same listing with `javap` and fails when it differs from the file, so a change to a public signature before the release candidate is a reviewed diff of that file in the same pull request, not something found by reading the code. Run `./gradlew apiCheck` to compare and `./gradlew apiDump` to rewrite the files after an intended change.

A file lists every `public` and `protected` member, with its generic types and its constant value, of the public types of the module, as defined above, and the permitted subclasses of a sealed type. Annotations, parameter names and the defaults of annotation members are not part of the listing. The snapshot is not a binary compatibility check: japicmp stays off until the final release.

[[experimentalMarks]]
== Experimental types

A type marked `(experimental)` in the tables below carries `@Experimental` (`io.micronaut.core.annotation.Experimental`). The meaning of the mark is explained in <<experimentalTypes,Types that are marked `@Experimental`>>, and every type that carries it is listed in the tables. A type without the mark is stable.
