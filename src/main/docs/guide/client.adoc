The `micronaut-graphql-tools-client` module is the GraphQL client of the library: a runtime for an application that calls a GraphQL server. It runs on the Micronaut HTTP client, so `micronaut.http.services.<id>.*`, filters and TLS apply unchanged. This page describes the low-level client, api:io.micronaut.graphql.tools.client.GraphQLHttpClient[], and the annotations of the declarative client. The runtime that implements a client interface and the compile-time checks of its operations arrive in later milestones, so the annotations only declare a client today.

== The low-level client

`GraphQLHttpClient` sends a `GraphQLRequest` that your code builds, with a document and variables of your own, and returns a `GraphQLResponse`. The data is typed (`GraphQLRequest.builder(Book.class)`, a `@Serdeable` type) or dynamic (`GraphQLRequest.builder()`, a `Map`). Inject it with `@GraphQLClient` on the field or the parameter, naming the service:

[source,java]
----
@Singleton
public class Books {

    @Inject
    @GraphQLClient("books")
    GraphQLHttpClient client;
}
----

The client needs Micronaut Serialization with its JSON implementation (`io.micronaut.serde:micronaut-serde-jackson`) in the application. Without it the application fails at start, and the message names that module. The client does not use Jackson.

=== Variants

[cols="2,5", options="header"]
|===
| Method | Result

| `execute`
| A reactive `Publisher` of one response. It is cold: each subscription sends the request.

| `executeAsync`
| A `CompletableFuture` of the response. Cancelling it cancels the call.

| `executeBlocking`
| The response, or an exception thrown to the caller.
|===

Each method has a second form that takes a customizer, a `Consumer<MutableHttpRequest<?>>` that changes the HTTP request of that call before it is sent, for example to add a header. The `execute` and `executeAsync` variants report every failure, including a request that cannot be sent, through the publisher or the future.

The reactive and the `CompletableFuture` variants complete on the event loop of the HTTP client, so a continuation that you attach must not block. `executeBlocking` called on an event loop thread, for example from a controller that returns a reactive type, throws a `GraphQLClientException` with the code `blocking-on-event-loop` and sends nothing; call it from a thread that may block, such as a `@ExecuteOn(TaskExecutors.BLOCKING)` method.

=== The request

A request is sent with POST by default. The body is JSON with the keys `query`, `operationName`, `variables` and `extensions` only, and a key without a value is left out. The `Content-Type` is `application/json` and the `Accept` header is `application/graphql-response+json, application/json;q=0.9`. The client sets the request attributes `graphql.operation.name` and `graphql.operation.type` (see `GraphQLClientAttributes`) for a filter to read.

`GraphQLRequest.Builder#httpMethod(HttpMethod.GET)` sends a query with GET instead: the parameters `query`, `operationName`, `variables` and `extensions` are URL-encoded in the URL, and the last two hold JSON. Only a query can be sent with GET; the builder rejects any other operation. A subscription is not sent over HTTP.

=== The server

The service id of `@GraphQLClient` is the Micronaut one, so the server comes from `micronaut.http.services.<id>.url` or `micronaut.http.services.<id>.urls` (several URLs are load balanced), and the timeouts, TLS, proxy and HTTP version settings of `micronaut.http.services.<id>.*` apply. The client adds no configuration key. A client filter with `@ClientFilter(serviceId = "<id>")` runs on each call.

The path of the endpoint is the `endpoint` member of `@GraphQLClient`, and `/graphql` when it is empty. A path in the service URL is not used.

=== Responses

A response is classified by its status and its body. A body is a GraphQL body when it is a JSON object with a `data` entry or at least one error.

[cols="2,5", options="header"]
|===
| Answer | Result

| Any 2xx status (even one that HTTP does not define) with a GraphQL body
| A `GraphQLResponse`. `dataOrThrow()` throws `GraphQLErrorsException` when it has errors.

| A 4xx or 5xx status other than 404 with a well-formed GraphQL body
| A `GraphQLResponse`, the same as above.

| A 2xx status with a body that starts like a GraphQL response but does not decode
| `GraphQLClientException` with the code `decode-error`.

| Any other answer: 404, a 3xx status, an empty body, a body that is not a GraphQL body (HTML, a JSON array, `{}`, a JSON error of a proxy), or a 4xx or 5xx body that does not decode
| `GraphQLTransportException` with the status and the headers.

| A timeout
| `GraphQLTransportException` with `isTimeout()` set and the code `transport-timeout`.

| A connection error, or no server for the service id
| `GraphQLTransportException` with the status `-1` and the cause.
|===

The media type of the response is not checked; the body is.

== The annotations

[cols="2,5", options="header"]
|===
| Annotation | Use

| `@GraphQLClient`
| Marks a client. On an interface it declares a client; on a field or a parameter it marks a low-level injection point.

| `@GraphQLOperation`
| Marks a method of a client interface as one GraphQL operation.

| `@GraphQLVariable`
| Binds a parameter of an operation method to a variable of the operation.
|===

== GraphQLClient

`@GraphQLClient` is a stereotype of the Micronaut `@Client` annotation, so the members that name the service resolve like those of `@Client`:

[cols="2,5", options="header"]
|===
| Member | Meaning

| `value`, `id`
| The service id or the URL of the server. Both are aliases of each other and of `@Client(id)`, so `@GraphQLClient("books")` reads the configuration under `micronaut.http.services.books`.

| `endpoint`
| The path of the GraphQL endpoint. An alias of `@Client(path)`.

| `webSocketEndpoint`
| The path of the WebSocket endpoint that subscriptions use. Empty means the value of `endpoint`.

| `schema`
| The name of the client schema that the operations are checked against at compile time.

| `configuration`
| The HTTP client configuration class. An alias of `@Client(configuration)`.
|===

[source,java]
----
@GraphQLClient(id = "books", endpoint = "/graphql")
public interface BookClient {

    @GraphQLOperation("query($id: ID!) { book(id: $id) { title } }")
    Book book(@GraphQLVariable("id") String bookId);
}
----

== GraphQLOperation and GraphQLVariable

`@GraphQLOperation` takes the GraphQL document in `value`, or the name of an operation of the client directory. `name` selects one operation of a document that holds several, and `method` is `POST` (the default) or `GET`; only a query can use `GET`. A method without `@GraphQLOperation` is left to the Micronaut HTTP client.

`@GraphQLVariable` names the variable that a parameter binds, without the dollar sign. A parameter without it binds the variable named like the parameter.
