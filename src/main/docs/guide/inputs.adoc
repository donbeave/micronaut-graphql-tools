== ArgumentValue

An `ArgumentValue<T>` argument or input field tells an omitted value from an explicit `null`. Besides `isOmitted()`, `isNull()`, `isPresent()` and `get()`, two methods read the value without a branch:

* `asOptional()` returns an `Optional` that is empty for an omitted value and for an explicit `null`.
* `ifPresent(Consumer)` runs the consumer only for a provided, non-null value.
