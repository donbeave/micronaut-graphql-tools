== Architecture rules

A native image needs configuration for every reflective access, so the build keeps the library free of it. `ArchitectureRulesSpec` fails when a class of the library or of `graphql-tools-binding` looks up a class, member or annotation reflectively (`Class.forName`, `getMethod`, `getDeclaredMethod`, `getDeclaredAnnotation`, `getEnumConstants`, `setAccessible`, `java.lang.reflect` types other than `Modifier`, `java.lang.invoke`), when it depends on Jackson, or when the public API exposes an internal type. The allowlist is empty: the type resolver contracts that a bean inherits are written by the compile-time visitor into the annotation metadata of the bean and read from the bean definition, so a class that is a type resolver only through an interface binds the same way on the JVM and in a native image (the build needs `micronaut-graphql-tools-processor`; see BC-33).
