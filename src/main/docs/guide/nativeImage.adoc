== Architecture rules

A native image needs configuration for every reflective access, so the build keeps the library free of it. `ArchitectureRulesSpec` fails when a class of the library or of `graphql-tools-binding` looks up a class, member or annotation reflectively (`Class.forName`, `getMethod`, `getDeclaredMethod`, `getDeclaredAnnotation`, `getEnumConstants`, `setAccessible`, `java.lang.reflect` types other than `Modifier`, `java.lang.invoke`), when it depends on Jackson, or when the public API exposes an internal type. The one remaining reflective read, in `GraphQLResolversRegistry`, is on an allowlist until #34 removes it.
