This page binds a small schema to a resolver. Every code example is shown in Java, Kotlin and Groovy; pick a tab.

1. Add the repository and the dependency. Milestone previews are published to the https://github.com/donbeave/micronaut-graphql-tools/packages[GitHub Packages] Maven registry of the repository, and GitHub Packages needs a token with the `read:packages` scope even to download a public package (see <<compatibility,Compatibility>>). No version is on Maven Central:
+
[source,groovy]
----
repositories {
    mavenCentral()
    maven {
        url = uri("https://maven.pkg.github.com/donbeave/micronaut-graphql-tools")
        credentials {
            username = providers.gradleProperty("gpr.user").orNull ?: System.getenv("GITHUB_ACTOR")
            password = providers.gradleProperty("gpr.key").orNull ?: System.getenv("GITHUB_TOKEN")
        }
        content { includeGroup("io.micronaut.graphql.tools") }
    }
}

dependencies {
    implementation(platform("io.micronaut.graphql.tools:micronaut-graphql-tools-bom:1.0.0-M4"))
    implementation("io.micronaut.graphql.tools:micronaut-graphql-tools")
}
----
+

+

  <repository>
    <id>graphql-tools</id>
    <url>https://maven.pkg.github.com/donbeave/micronaut-graphql-tools</url>

</repositories>

<dependencyManagement>
  <dependencies>
    <dependency>
      <groupId>io.micronaut.graphql.tools</groupId>
      <artifactId>micronaut-graphql-tools-bom</artifactId>
      <version>1.0.0-M4</version>
      <type>pom</type>
      <scope>import</scope>

<dependencies>
  <dependency>
    <groupId>io.micronaut.graphql.tools</groupId>
    <artifactId>micronaut-graphql-tools</artifactId>
  </dependency>
</dependencies>

+
To use a build of your own checkout instead, run `./gradlew publishToMavenLocal` in the repository and add `mavenLocal()` (Gradle) to the repositories; Maven reads its local repository without a declaration (see `CONTRIBUTING.md`). That publishes to your machine only.
+
The BOM (`micronaut-graphql-tools-bom`) sets the version of every module of the library, so the other module snippets of this guide name no version. The library does not bring a JSON codec (BC-26). Add the one your application uses, for example `micronaut-jackson-databind` or `micronaut-serde-jackson`, to the same `dependencies` block.

2. Define the GraphQL schema in `.graphqls` files in the `src/main/resources/graphql` folder. The library finds them at startup (see the Schema page), and a `schema { }` block is optional:
+
[source,graphql]
----
type Query {
  allBooks: [Book!]!
}

type Book {
  id: ID!
  title: String!
}
----

== Annotations

The library provides these annotations (package `io.micronaut.graphql.tools.annotation`):

* `@GraphQLRootResolver` defines a root-level resolver, a GraphQL entry point such as a query or mutation. Like `@GraphQLTypeResolver`, it makes no bean: the class needs `@Singleton` or another scope annotation.
* `@GraphQLType` maps a Java class to a GraphQL type.
* `@GraphQLTypeResolver` specifies a resolver for a field of a specific GraphQL type, to map nested or complex fields.
* `@GraphQLInput` defines a GraphQL input type, structured input data for mutations or queries.
* `@GraphQLField` marks a method of a `@GraphQLType` class as a field resolver, so that methods with arguments (or a `DataFetchingEnvironment` parameter) can back a GraphQL field. `@GraphQLField("name")` on a method or a property binds the field of that name (see <<renaming,Binding a field to a differently named member>>).
* `@GraphQLSchemaCoordinate("Type.field")` names the field a resolver method binds; it is meant for resolver contracts (interfaces).

The marker interfaces `QueryResolver`, `MutationResolver`, `SubscriptionResolver` and `TypeResolver<T>` (package `io.micronaut.graphql.tools.resolver`) declare resolver contracts without an annotation; see <<resolverContracts,Resolver Contracts>>.

GraphQL enums map to Java enums annotated with `@Introspected`, and unions and interfaces to Java interfaces, without an annotation of their own.
