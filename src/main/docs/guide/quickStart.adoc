This page binds a small schema to a resolver. Every code example is shown in Java, Kotlin and Groovy; pick a tab.

1. Add the repository and the dependency. Milestone previews are published to the https://github.com/donbeave/micronaut-graphql-tools/packages[GitHub Packages] Maven registry of the repository, and GitHub Packages needs a token with the `read:packages` scope even to download a public package (see <<compatibility,Compatibility>>). No version is on Maven Central:
+
[source,groovy]
----
repositories {
    mavenCentral()
    maven {
        url = uri("https://maven.pkg.github.com/donbeave/micronaut-graphql-tools")
        credentials {
            username = providers.gradleProperty("gpr.user").orNull ?: System.getenv("GITHUB_ACTOR")
            password = providers.gradleProperty("gpr.key").orNull ?: System.getenv("GITHUB_TOKEN")
        }
        content { includeGroup("io.micronaut.graphql.tools") }
    }
}

dependencies {
    implementation("io.micronaut.graphql.tools:micronaut-graphql-tools:1.0.0-M1")
}
----

2. Define the GraphQL schema in `.graphqls` files in the `src/main/resources/graphql` folder. The library finds them at startup (see the Schema page), and a `schema { }` block is optional:
+
[source,graphql]
----
type Query {
  allBooks: [Book!]!
}

type Book {
  id: ID!
  title: String!
}
----

3. Optional: to load the schema yourself, define a `TypeDefinitionRegistry` bean. It is used instead of the discovered files, so the example loads its own file, `schema.graphqls` at the root of the classpath (a file in the default folder is `classpath:graphql/schema.graphqls`). == Annotations

The library provides these annotations (package `io.micronaut.graphql.tools.annotation`):

* `@GraphQLRootResolver` defines a root-level resolver, a GraphQL entry point such as a query or mutation.
* `@GraphQLType` maps a Java class to a GraphQL type.
* `@GraphQLTypeResolver` specifies a resolver for a field of a specific GraphQL type, to map nested or complex fields.
* `@GraphQLInput` defines a GraphQL input type, structured input data for mutations or queries.
* `@GraphQLField` marks a method of a `@GraphQLType` class as a field resolver, so that methods with arguments (or a `DataFetchingEnvironment` parameter) can back a GraphQL field.
* `@GraphQLSchemaCoordinate("Type.field")` names the field a resolver method binds; it is meant for resolver contracts (interfaces).

GraphQL enums map to Java enums annotated with `@Introspected`, and unions and interfaces to Java interfaces, without an annotation of their own.
