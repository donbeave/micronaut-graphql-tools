This page binds a small schema to a resolver. Every code example is shown in Java, Kotlin and Groovy; pick a tab.

1. Add the dependency. No version is on Maven Central yet; the snapshot of the current development line is `1.0.0-SNAPSHOT`:
+
[source,groovy]
----
implementation("io.micronaut.graphql.tools:micronaut-graphql-tools:1.0.0-SNAPSHOT")
----

2. Define the GraphQL schema in a `schema.graphqls` file, for example in the `src/main/resources` folder:
+
[source,graphql]
----
type Query {
  allBooks: [Book!]!
}

type Book {
  id: ID!
  title: String!
}
----

4. Add a root resolver. The method name is the field name in the schema, and the class is bound by `@GraphQLRootResolver`:

== Annotations

The library provides these annotations (package `io.micronaut.graphql.tools.annotation`):

* `@GraphQLRootResolver` defines a root-level resolver, a GraphQL entry point such as a query or mutation.
* `@GraphQLType` maps a Java class to a GraphQL type.
* `@GraphQLTypeResolver` specifies a resolver for a field of a specific GraphQL type, to map nested or complex fields.
* `@GraphQLInput` defines a GraphQL input type, structured input data for mutations or queries.
* `@GraphQLField` marks a method of a `@GraphQLType` class as a field resolver, so that methods with arguments (or a `DataFetchingEnvironment` parameter) can back a GraphQL field.
* `@GraphQLSchemaCoordinate("Type.field")` names the field a resolver method binds; it is meant for resolver contracts (interfaces).

GraphQL enums map to Java enums, and unions and interfaces to Java interfaces, without an annotation of their own.
