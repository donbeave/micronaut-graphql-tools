# docs-examples-kotlin

The quickstart of the user guide in Kotlin: a schema, a `TypeDefinitionRegistry` bean, a root resolver and a test that runs the first
query. The guide includes these sources with the `snippet::` macro (`project-base="docs-examples"`). The module is not published,
and the behavioural tests stay in the `test-suite-*` modules.

```
./gradlew :micronaut-docs-examples-kotlin:test
```
